Save changes to the website

With a GitHub key on this phone, your ticks, shelf prices, new items and photos save to the public link by themselves (a few seconds after you stop, or once you're back online). Everyone who opens the link gets them. Without a key, changes stay on this phone.

How to make the key (2 minutes)
  1. Open github.com/settings/personal-access-tokens/new (signed in as OldTalez).
  2. Name it "Wardrobe phone", pick an expiry.
  3. Repository access: Only select repositories → sirfay-wardrobe.
  4. Permissions → Repository → Contents: Read and write. Nothing else.
  5. Generate, copy the key, paste it here, Save key.

The key stays in this browser only; it is never put in saved copies or helper copies. Lost the phone? Delete the key on GitHub and it stops working.

Quick start

  1. Rack shows every piece on a hanger. Tap one for the big photo (double-tap or pinch to see the fabric), price, sizes and the store link.
  2. List shows everything in one list. Tap a name to open the store's page, tap the picture for details, tap the circle when it's bought.
  3. Shop is for the store: grouped by store, his sizes at the top, type the shelf price to compare.
  4. Add adds new pieces from a link, sends the list to a helper and saves changes to the website.

Put it on your phone

  1. Open oldtalez.github.io/sirfay-wardrobe once while you have internet. The phone keeps a copy, so after that it opens with no signal.
  2. Android (Chrome): menu ⋮ → Add to Home screen. iPhone (Safari): Share → Add to Home Screen.
  3. Open it from the orange hanger icon. It opens like an app, full screen.

Store links need internet to open. Everything else works offline.

Getting around

  1. Use the tabs at the bottom (at the top on a computer). Tap the tab you're on to jump back to the top.
  2. Back takes you to the page you were on: the ‹ Back button at the top left, your phone's back gesture or back button. Open details close first.
  3. On the first page, going back shows "Go back again to close", so the app doesn't close by accident.
  4. Details slide up from the bottom: swipe the grey bar down, tap outside, or tap ✕ to close.

Adding items

  1. Go to Add and paste a product link, then Get details. The app fills in what it can: name, brand, store, price, discount, sizes, material, where it's from.
  2. Some stores block apps. Then open No details came through? Paste the product page: on the store page select all and copy, paste it in, tap Read it.
  3. Fill in what to buy (size, how many, max price, similar OK) and tap Add to the rack.
  4. Many at once: Add many links at once, one link per line. Open each afterwards to check it.
  5. To refresh an item later, open it and tap Get details from link.

Adding photos

  1. In List, tap Add photo from the store under an item. The store page opens and a bar appears at the bottom of the app with that item's name.
  2. On the store page, press and hold the product photo and choose Copy (computer: right-click → Copy image).
  3. Come back to the app and tap Paste in the bar (computer: Ctrl+V or ⌘V). The plain background is removed and the photo is saved on that item.
  4. Saved the picture instead? Tap File and pick it. Inside an item you can also Paste photo, Add photo or Remove this photo.

Studio shots on white look best on the rack. Check it's the right colour before pasting.

In the store

  1. Open Shop. Stores are grouped with the thrift route first. His sizes are at the top; orange ones still need confirming.
  2. Type the Shelf $ price to see if it's cheaper than online.
  3. Tick the circle when it's in the bag. The spent total and budget bar update.

Sending the list to a helper

  1. In Shop, tap Send the list, add their name and a message, pick the items.
  2. Send helper copy makes one file with every detail and photo. Send it on WhatsApp. It opens on their phone with no internet.
  3. They tap Got it / Got similar / Not found, add the price and a photo, then Send update.
  4. You tap Import their update in Shop and pick their file. Your list is ticked for you.

Or simply send them the website link: they see the latest list.

Save changes to the website (GitHub key)

Without a key, ticks and photos stay on the phone you made them on. With a key, they save to the website by themselves and everyone who opens the link gets them. You make the key once per phone.

Make the key

  1. On the phone, open github.com/settings/personal-access-tokens/new and sign in as OldTalez.
  2. Token name: "Wardrobe phone". Expiration: pick a date (90 days is fine; make a new one when it ends).
  3. Repository access: choose Only select repositories and pick sirfay-wardrobe.
  4. Permissions → Repository permissions → Contents: set to Read and write. Leave everything else as it is.
  5. Tap Generate token, then copy the key. It starts with github_pat_. GitHub shows it only once.

Put it in the app

  1. Open the app from the website link (not a saved file), go to Add → Save changes to the website.
  2. Paste the key and tap Save key. It says "Key saved" when GitHub accepts it.
  3. That's it. Change something: a few seconds after you stop, it saves. Offline? It saves when you're back online.

The dot at the top tells you how it's going

Green: saved, or up to date.Orange, breathing: saving, or waiting for internet.Red: not saved. Tap and hold it to read why, or open Add and tap Sync now.

Other phones get the changes the next time they open the link with internet. The website itself updates about a minute after a save. Two phones can save at the same time: both changes are kept, the newest change to each item wins.

Lost the phone, or done? Open github.com/settings/personal-access-tokens, open "Wardrobe phone" and Delete. It stops working at once. On a phone you keep, Remove key in Add takes it off.

Fixing problems

  • Red dot, "GitHub 401": the key is wrong or expired. Make a new one and Save key.
  • Red dot, "GitHub 403" or "404": the key can't write to sirfay-wardrobe. Check Only select repositories → sirfay-wardrobe and Contents: Read and write.
  • Another phone doesn't show my change: open the link there with internet, wait a minute, pull down or reopen. Make sure the dot on your phone went green.
  • Paste does nothing: copy the photo again, or save it and use File. Some browsers ask permission to read the clipboard: allow it.
  • "Get details" finds nothing: the store blocks apps. Use Paste the product page.
  • A new version came out: it never removes your ticks, prices or photos; changes merge item by item.

Privacy

  • The website is public: anyone with the link can see the list, his sizes and the photos. Search engines are told not to list it.
  • The GitHub key stays in your phone's browser. It is never put in saved copies, helper copies or the website.
  • "Get details" sends only the product link to the r.jina.ai reader. Untick it in Add if you'd rather not.
